# Demo script (target)

1. Explain the operator's expansion need and show the synthetic/demo label where applicable.
2. Connect operator wallet and prove source-wallet ownership.
3. Show a recognized source-chain revenue transaction and its successful verification on Creditcoin.
4. Inspect the evidence period, asset, provenance and freshness. Explain telemetry issuer trust separately.
5. Show the versioned policy and calculation of available credit.
6. Fund the vault with test assets, request the loan and show the disbursement transaction.
7. Repay and show the updated loan state and wallet-linked credit history.
8. Attempt reused or invalid evidence and show rejection.

Prepare explorer links and seeded test assets. If showing recorded evidence due to network availability, say so. Never describe a mock run as live cryptographic verification.
